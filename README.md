# JS — подготовка к собеседованиям

Учебный стенд: краткая теория по теме JS + популярные вопросы с собеседований + задачи
с автопроверкой. Каждая задача — отдельная карточка: код слева, её проверки справа.
Писать можно в браузере или в WebStorm — файлы общие.

_Контекст проекта, требования и контракты — в [CONTEXT.md](CONTEXT.md)._

## Быстрый старт

1. Запусти сервер из папки проекта: `node serve.js`
2. Открой http://127.0.0.1:8127 и выбери тему в меню.
3. Разверни «📖 Теория и вопросы» — конспект и вопросы с собеседований.
4. В каждой карточке: условие — в синем блоке сверху; код пиши между маркерами
   `// ▼▼▼ ПИШИ СВОЙ КОД ЗДЕСЬ ▼▼▼` … `// ▲▲▲ КОНЕЦ КОДА ▲▲▲`
   (ниже маркера — проверки, их не меняй) → «▶ Запустить» (Ctrl+Enter),
   результаты — под кодом.
5. «📁 Папка темы» — один раз укажи папку темы, дальше «💾 В файл» (Ctrl+S)
   на карточке пишет прямо в её файл без диалогов. WebStorm подхватит с диска.
6. В шапке темы — прогресс: «зелёные задачи: N из M».

## Синхронизация (без рассинхрона)

- Файл карточки — источник истины: при открытии темы редактор грузит файл и сразу выполняет его.
- Черновик в localStorage — только автосейв на случай падения; при расхождении карточка
  покажет «Черновик отличается от файла. [Открыть черновик]».
- Статусы на каждой карточке: «файл: синхронизирован ✓ / есть несохранённые изменения».

## Режимы страницы

| Режим | Как открыть | Что умеет |
|---|---|---|
| Полный (карточки) | `node serve.js` → http://127.0.0.1:8127 | Теория, редакторы с подсветкой, запуск по карточкам, запись в файлы |
| Совместимости | двойной клик по `index.html` | Карточки выполняются по очереди автоматически, решения — через WebStorm |

Запись в файлы (File System Access API) — Chrome/Edge.

## Структура

- `index.html` + `style.css` — страница: меню, теория, тулбар темы, карточки, DOM-песочница.
- `runner.js` — хелперы `section/log/check/tryRun` (фабрика `makeHelpers` на карточку),
  меню тем, file://-режим, перехват console.
- `editor.js` — движок карточек: редакторы CodeMirror, запуск, автосейв, запись в файл,
  привязка папки темы, прогресс «зелёных».
- `vendor/` — `marked.min.js` (теория) и `codemirror.bundle.js` (редактор, CodeMirror 6, MIT);
  пересборка: `cd build && npm install && npm run build`.
- `build/` — сборка редактора, `annotate-stubs.mjs` (маркеры в задачах),
  `extract-descriptions.mjs` (вынос условий задач в index.json),
  `check-cards.mjs` (**проверка самодостаточности карточек — запускай после правки задач**),
  `migrate-to-folders.mjs` + `fix-selfcontained.mjs` (одноразовая миграция структуры).
- `serve.js` — статический сервер.
- `topics/<NN-slug>/` — папка темы:
  - `theory.md` — теория + вопросы с собеседований;
  - `index.json` — порядок карточек и markdown-условия (`description`), рендерятся над редактором;
  - `01-task.js, 02-task.js… 0M-demo.js` — карточки: маркеры + заготовка + проверки этой задачи
    (условий-комментариев в коде нет); каждая самодостаточна.

## Как добавить задачу

1. В папке темы создай `NN-task.js` (или `NN-demo.js`): `section('Заголовок')`, условие —
   НЕ в коде, а в `index.json`, заготовка с маркером `// ▼▼▼ ПИШИ СВОЙ КОД ЗДЕСЬ ▼▼▼`
   первой строкой внутри, проверки через `check/tryRun`.
2. Добавь файл в `index.json` темы: `description` (стиль — см. CONTEXT.md) и `source` —
   откуда задача; `sourceUrl` — только проверенные ссылки.
3. `node build/check-cards.mjs` — убедись, что карточка самодостаточна
   (и не ходит в сеть при проверке — `globalThis.__CARD_CHECKER__`).

## Заметки

- Тесты с таймерами дописывают результат позже — «выполнено» в футере не значит, что проверки кончились.
- `check()` сравнивает структурно (deep equal), NaN равен NaN.
- Повторный запуск карточки чистит её вывод и общий `#sandbox` (DOM-тема): в песочнице —
  элементы последней запущенной карточки.
- Ревью решений: попроси ассистента «проверь 02-scope-and-closures».

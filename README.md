# JS — подготовка к собеседованиям

Учебный стенд: краткая теория по теме JS + популярные вопросы с собеседований + задачи.
Решение пишешь сам в файл темы и сразу проверяешь его в браузере. Ничего ставить не нужно.

## Как работать

1. Открой `index.html` двойным кликом (работает с диска, без сервера и сборки).
   Запасной вариант: `node serve.js` → http://127.0.0.1:8127 (если file:// чем-то не устроит).
2. Выбери тему в меню сверху.
3. Теория и вопросы — в `topics/<номер>-<тема>.md` (в WebStorm рендерится как Markdown).
4. Реши задачи в соседнем файле `topics/<номер>-<тема>.js` — там заготовки функций с `// TODO`
   и готовые самопроверки. Заглушки безопасны: нерешённая задача даёт красную строку,
   а не падение всего файла (для опасных вызовов в тестах используется `tryRun`).
5. Сохрани файл (Ctrl+S) и обнови страницу (F5) — проверки внизу позеленеют.
6. Когда готов — попроси меня: «проверь 02-scope-and-closures» (или просто номер темы).
   Я прочитаю файл, разберу решение, укажу краевые случаи и что могут спросить «на добивание».

## Структура

- `index.html` — раннер: меню тем, вывод, DOM-песочница.
- `runner.js` — хелперы для задач: `section()`, `log()`, `check(название, факт, ожидание)`, `tryRun()`.
- `topics/*.md` — краткая теория, примеры, вопросы с собеседований.
- `topics/*.js` — задачи с TODO и самопроверкой.

Темы пронумерованы от базовых к продвинутым — номера в именах файлов держат сортировку.

## Темы

| № | Тема | Что тренируем |
|---|------|---------------|
| 01 | Типы и приведение | typeof, ==/===, NaN, falsy, Object.is |
| 02 | Скоуп и замыкания | var/let/const, hoisting, debounce, throttle, memoize |
| 03 | this и call/apply/bind | правила this, свой bind/call, потеря контекста |
| 04 | Функции и каррирование | HOF, стрелочные, arguments, curry, pipe/compose |
| 05 | Прототипы и классы | свой new/instanceof, наследование ES5 и class |
| 06 | Объекты и копирование | ссылки, deepClone, shallowEqual, mergeDeep |
| 07 | Массивы | полифиллы map/reduce, unique, flatten, groupBy, chunk |
| 08 | Событийный цикл | микро/макрозадачи, порядок вывода, блокировка стека |
| 09 | Promise и async/await | свой Promise.all, retry, mapWithLimit, sleep |
| 10 | DOM и события | делегирование, всплытие, CustomEvent, debounce на input |

## Как добавить тему

1. Скопируй любую пару `topics/NN-*.md` + `topics/NN-*.js`, поменяй номер и содержимое.
2. В `runner.js` добавь строку в массив `TOPICS`.

## Заметки

- Тесты с таймерами (debounce, throttle, sleep) дописывают результат чуть позже остального вывода — это нормально.
- `check()` сравнивает структурно (deep equal), NaN равен NaN.
- Тема 10 работает с серой зоной «DOM sandbox» на странице: скрипт создаёт в ней элементы
  и проверяет их синтетическими кликами.

# JS — подготовка к собеседованиям

Учебный стенд: краткая теория по теме JS + популярные вопросы с собеседований + задачи.
Код можно писать прямо в браузере (песочница с кнопкой «Запустить»), а можно в WebStorm —
файлы `topics/*.js` синхронизируются кнопкой «💾 В файл».

## Быстрый старт

1. Запусти сервер (один раз в терминале, из папки проекта): `node serve.js`
2. Открой http://127.0.0.1:8127 и выбери тему в меню.
3. Разверни «📖 Теория и вопросы» — конспект и вопросы с собеседований.
4. Пиши решения в редакторе слева вместо `// TODO` → «▶ Запустить» (Ctrl+Enter).
   Красные проверки позеленеют.
5. «💾 В файл» (Ctrl+S) записывает код из редактора в настоящий `topics/NN-*.js`
   (в диалоге выбери существующий файл темы — он перезапишется). Дальше — коммит как обычно.

## Как устроена синхронизация (чтобы не было рассинхрона)

- **Файл `topics/NN.js` — источник истины.** При открытии темы редактор загружает именно файл
  и сразу выполняет его (то же, что раньше давал F5).
- **Черновик в localStorage** — только автосейв на случай падения браузера. Если черновик
  отличается от файла, при загрузке появится жёлтый баннер: «Взять файл» или «Открыть черновик».
- Статусная строка под редактором всегда показывает два состояния: черновик и файл
  («синхронизирован ✓» / «есть несохранённые изменения»).
- WebStorm подхватывает файл, записанный браузером, с диска — и наоборот, правки из IDE
  видны в песочнице по «⟲ Из файла» или простому F5.

## Два режима работы страницы

| Режим | Как открыть | Что умеет |
|---|---|---|
| Полный (песочница) | `node serve.js` → http://127.0.0.1:8127 | Теория на странице, редактор, запуск без перезагрузки, запись в файл |
| Совместимости | двойной клик по `index.html` (file://) | Старый режим: автозапуск файла темы, решения через WebStorm |

Запись в файл (File System Access API) работает в Chrome/Edge; первый раз браузер спросит
разрешение и путь — дальше в рамках сессии сохраняет сразу.

## Структура

- `index.html` + `style.css` — страница-стенд (меню, теория, редактор, вывод, DOM-песочница).
- `runner.js` — хелперы для задач (`section`, `log`, `check`, `tryRun`), меню тем, режим file://.
- `editor.js` — песочница: загрузка .md/.js, запуск, автосейв, запись в файл, баннер черновика.
- `vendor/marked.min.js` — рендер markdown (Marked, MIT).
- `serve.js` — крошечный статический сервер.
- `topics/*.md` — теория + вопросы с собеседований (источник для панели на странице).
- `topics/*.js` — задачи с TODO и самопроверками.

## Как добавить тему

1. Скопируй пару `topics/NN-*.md` + `topics/NN-*.js`, поменяй номер и содержимое.
2. В `runner.js` добавь строку в массив `TOPICS`.

## Заметки

- Тесты с таймерами (debounce, throttle, sleep) дописывают результат позже остального вывода.
- `check()` сравнивает структурно (deep equal), NaN равен NaN.
- Повторный «▶ Запустить» чистит вывод и DOM-песочницу; таймеры прошлого прогона могут дописать пару строк — это нормально, лечится F5.
- Ревью решений: попроси ассистента «проверь 02-scope-and-closures» — он прочитает файл и разберёт решение.

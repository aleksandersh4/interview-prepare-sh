# 03 · this, call / apply / bind

## Теория (кратко)

- `this` определяется **в момент вызова**, а не объявления (кроме стрелочных функций).
- Правила, от частного к общему (кто выше — тот и выигрывает):
  1. `new Fn()` → `this` = newly created object;
  2. `fn.call(ctx, ...)`, `fn.apply(ctx, [])`, `fn.bind(ctx)` → `this` = `ctx` (явная передача);
  3. `obj.fn()` → `this` = `obj` (неявная передача — «точка слева»);
  4. `fn()` → `undefined` в strict mode, `globalThis` (window) — вне strict;
  5. стрелочная функция — особый случай: `this` берётся **лексически** из внешнего скоупа
     на момент создания, задать его нельзя вообще.
- `call` и `apply` **вызывают** функцию сразу и отличаются только передачей аргументов
  (списком и массивом). `bind` **не вызывает**: возвращает новую функцию с зафиксированным
  `this` и частично применёнными аргументами; повторный `bind` первый уже не переопределит.
- **Потеря контекста**: `const f = obj.fn; f()` — `this` уже не `obj`. То же происходит при передаче
  метода как колбэка (`setTimeout(obj.fn, 100)`, `arr.forEach(obj.fn)`).
- Фиксы: `bind`, стрелочная обёртка `() => obj.fn()`, поле-стрелка в классе (`handler = () => {}`).
- Стрелочные функции: нет `this`, `arguments`, `super`, `new.target`; не конструкторы;
  идеальны как колбэки внутри методов, опасны как сами методы.

## Примеры

```js
const user = { name: 'Аня', greet() { return 'Привет, ' + this.name; } };
user.greet();                          // 'Привет, Аня'
const f = user.greet;
f();                                   // this потерян: 'Привет, undefined'
user.greet.call({ name: 'Борис' });    // 'Привет, Борис'
user.greet.apply({ name: 'Вера' });    // то же, аргументы — массивом
const bound = user.greet.bind(user);
bound();                               // 'Привет, Аня' — всегда

// Стрелка берёт this снаружи:
const obj = {
  name: 'Объект',
  regular() { return this.name; },        // 'Объект'
  arrow: () => (this && this.name),       // undefined — this НЕ obj, а скоуп снаружи
  delayed() { setTimeout(() => this.regular(), 100); }, // стрелка сохранила this метода — ок
};
```

# 06 · Объекты и копирование

> Задачи — карточками на странице темы; файлы: `01-task.js`, `02-task.js`… в этой папке.

## Теория (кратко)

- Присваивание объекта копирует **ссылку**: `const b = a` — это один и тот же объект под двумя именами.
  Сравнение `===` у объектов сравнивает ссылки: два «одинаковых» объекта не равны.
- **Поверхностная копия (shallow)**: `{ ...obj }`, `Object.assign({}, obj)`, `arr.slice()`, `arr.toSorted()`.
  Верхний уровень новый, вложенные объекты/массивы — всё ещё общие с оригиналом.
- **Глубокая копия (deep)**:
  - `structuredClone(obj)` — встроенный способ (знает Date, Map, Set, циклы ссылок;
    не умеет функции и DOM);
  - `JSON.parse(JSON.stringify(obj))` — теряет `undefined`, функции, `Date` (станет строкой),
    `Map`/`Set` (пустые объекты), `NaN`/`Infinity` (null);
  - своя рекурсия — задача №1 (и самый частый запрос на собеседовании).
- Утилиты: `Object.keys / values / entries` и обратный `Object.fromEntries`.
- **Дескрипторы свойств**: `Object.defineProperty(obj, key, { value, writable, enumerable, configurable })`,
  геттеры/сеттеры `get/set`. `enumerable: false` прячет свойство из `keys` и `for...in`.
- `Object.freeze` / `seal` — **поверхностные**: вложенные объекты остаются изменяемыми.
- `??` (nullish) — «только если null/undefined», `||` — «если falsy»: `0 || 10` → 10, но `0 ?? 10` → 0.
- Безопасный доступ: `user?.address?.street`, `fn?.()`, `arr?.[0]`, присваивание `x ??= v`.

## Примеры

```js
const a = { n: 1 };
const b = a;
b.n = 2;                       // a.n тоже 2 — один объект
a === b;                       // true
{ n: 2 } === { n: 2 };         // false — разные объекты

const shallow = { ...a };      // новый верхний уровень
const deep = structuredClone({ x: { y: 1 } });

0 || 'дефолт';                 // 'дефолт' — 0 falsy
0 ?? 'дефолт';                 // 0 — 0 не null/undefined

const frozen = Object.freeze({ inner: { k: 1 } });
frozen.inner.k = 2;            // сработает! freeze не глубокий
```

# 04 · Функции и каррирование

> Задачи: [`04-functions-and-currying.js`](04-functions-and-currying.js) · Запуск: `index.html?topic=04-functions-and-currying`

## Теория (кратко)

- Функции в JS — объекты **первого класса**: их можно присваивать, передавать аргументом,
  возвращать из других функций, хранить в структурах.
- **Функция высшего порядка (HOF)** — принимает функцию и/или возвращает функцию.
  Вся стандартная библиотека (`map`, `filter`, `setTimeout`, `addEventListener`) — HOF.
- **Стрелочные vs обычные** (минимум, что просят перечислить):
  1. нет своего `this` — берётся лексически;
  2. нет `arguments` (есть `rest`);
  3. нельзя вызвать с `new`, нет `prototype`;
  4. нельзя использовать как метод с контекстом;
  5. короче и неименованны удобнее для колбэков.
- `arguments` — псевдомассив «все аргументы вызова» у обычных функций;
  настоящий массив: `Array.from(arguments)` или `const args = [...arguments]`.
  У стрелочных его нет — используют rest-параметры `(...args) => ...` (настоящий массив).
- **Каррирование**: `f(a, b, c)` → `f(a)(b)(c)`. **Частичное применение**: зафиксировать
  часть аргументов сейчас, остальные — позже (`bind` как раз умеет).
- **Композиция**: `pipe(...fns)` — применить слева направо; `compose(...fns)` — справа налево.
- Параметры по умолчанию: `function f(x = 1) {}`; rest: `function f(...nums) {}`;
  spread при вызове: `f(...arr)`.

## Примеры

```js
// HOF: логирование времени вызова любой функции
const timed = (fn) => (...args) => {
  const t = performance.now();
  const res = fn(...args);
  console.log(fn.name, Math.round(performance.now() - t), 'мс');
  return res;
};

// Частичное применение через bind:
const pow = (base, exp) => base ** exp;
const square = pow.bind(null, 2);   // base зафиксирован = 2
square(3);                          // 8 — осторожно, base=2 → 2^3

// Каррирование:
const curry = (fn) => (...args) =>
  args.length >= fn.length ? fn(...args) : (...next) => curry(fn)(...args, ...next);
```

## Задачи (в js-файле)

1. **`curry(fn)`** — каррирование по арности (`fn.length`), вызовы можно группировать: `f(1)(2,3)`.
2. **`sum(...)`** — сумма с переменной глубиной: `sum(1)(2)(3)()`, `sum(1,2)(3)()`.
3. **`pipe(...fns)`** и **`compose(...fns)`** — композиция в оба направления.
4. **`average()`** — среднее через `arguments` (не стрелка!), 0 для пустого вызова.

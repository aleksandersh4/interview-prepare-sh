## Как отвечать (скелет)
- Инкапсуляция — данные и работа с ними вместе, детали скрыты (private-поля сервиса, `#field`).
- Наследование — переиспользование поведения через иерархию (в Angular почти не нужно — композиция).
- Полиморфизм — один интерфейс, разные реализации: `PaymentMethod.charge()` у Card/SBP; полиморфный вызов вместо switch по типу.
- Абстракция — работа с сутью, а не деталями: интерфейс `Storage` вместо localStorage-деталей.

# Паттерны GoF в Angular

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Singleton — сервисы `providedIn: "root"` (инстанс на приложение; осознанно, без глобального состояния-свалки).
- Factory — фабричные провайдеры `useFactory`, создание сложных объектов.
- Strategy — interchangeable-сервисы за одним токеном (например, разные схемы логирования).
- Observer — RxJS/EventEmitter/signals+effect: подписки на изменения.
- Decorator — interceptors, DI-декораторы (@Component — тоже декларативный декоратор, но из другой оперы).
- Facade — сервис-фасад над несколькими API для компонента; Adapter — обёртка над легаси/чужим API.

## Что могут спросить дополнительно
- Назови паттерн из RxJS-подписки. (Observer/Observable)

## Красные флажки
- Паттерн ради паттерна; не можешь назвать свой живой пример.

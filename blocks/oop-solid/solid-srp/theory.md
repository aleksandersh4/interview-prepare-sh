# SRP: единственная ответственность

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Одна причина для изменения = одна ответственность. Не «один метод», а одна роль.
- В Angular: компонент — представление; сервис — домен/данные; не смешивать HTTP, форматирование и UI-логику.
- Симптомы нарушения: класс на 500 строк, «сервис всего», правки в одном файле по разным поводам.
- Выгода: тестируемость, безопасные изменения, переиспользование.

# LSP: подстановка Барбары Лисков

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Наследник обязан соблюдать контракт родителя: где работает базовый — работает и подкласс, без сюрпризов.
- Нарушения: потомок бросает там, где родитель не бросал; усиливает предусловия; ослабляет постусловия; «потомку нельзя» вызывать часть методов (EmptyStack.pop у «readonly»-наследника).
- Классический пример: Square extends Rectangle ломает setWidth/setHeight.
- Лечение: не наследовать, если контракт не соблюдается; выделить общий интерфейс поменьше.

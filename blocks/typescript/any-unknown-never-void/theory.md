# any, unknown, never, void

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `any` — выключает проверку типов; допустим для миграции и `JSON.parse`, в коде — почти всегда зло.
- `unknown` — «что-то неизвестное»: присвоить можно всё, использовать — только после сужения (typeof/схема). Безопасная замена any на входах.
- `never` — «значения не будет»: бросающая функция, недостижимые ветки, exhaustive-check в switch (`default: const x: never = value`).
- `void` — «возврат не важен» (функция ничего не возвращает осмысленного).

## Красные флажки
- «unknown — это то же any». Нет: unknown не даёт вызывать методы.

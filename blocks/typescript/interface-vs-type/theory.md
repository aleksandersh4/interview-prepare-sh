# interface против type

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `interface` — только объектные формы; расширение `extends`; declaration merging (два объявления склеиваются — и плюс, и риск).
- `type` — объединения, примитивы, кортежи, mapped/conditional, вычисляемые ключи; «пересечение» через `&`.
- Практика команды: interface для публичных API/объектов, type для union/утилитарного — главное единообразие.
- При пересечении несовместимого `&` даст never-поля — ловится труднее, чем конфликт `extends`.

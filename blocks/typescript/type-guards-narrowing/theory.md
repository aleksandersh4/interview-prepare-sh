# Сужение типов: guards, in, предикаты, asserts

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Сужение автоматически: `typeof`, `instanceof`, проверка `in`, truthiness, `Array.isArray`.
- Пользовательский guard: `function isCat(a: Animal): a is Cat` — компилятор верит предикату.
- `asserts x is T` / `asserts x` — функция либо подтверждает, либо бросает (валидация на границе).
- Discriminated unions: `type: "circle" | "square"` + switch — идиома для форм данных.
- Библиотеки схем (zod) генерируют и тип, и runtime-guard — одна правда для API.

# Дженерики: extends, default, вывод типов

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Обобщения — «переменные типов»: `function first<T>(arr: T[]): T` сохраняет связь входа и выхода.
- Ограничение: `T extends { id: string }` — доступ к полям внутри.
- Дефолты: `<T = string>`; несколько параметров `<K, V>`.
- Вывод: TypeScript сам выводит T из аргументов; явные параметры — редко.
- Джинерики у классов/интерфейсов (Repository<T>), функциональные — у утилит.

## Что могут спросить дополнительно
- `T extends any` vs без ограничения — разница?
- Зачем дженерик, если можно union? (связь типов между позициями)

## Красные флажки
- Джинерик ради джинерика: `<T>` который нигде не связан.

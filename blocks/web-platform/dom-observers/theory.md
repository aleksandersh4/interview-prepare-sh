# IntersectionObserver, ResizeObserver, MutationObserver

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `IntersectionObserver` — элемент вошёл/вышел из вьюпорта (или пересёк другой элемент): ленивые картинки, бесконечный скролл, `@defer on viewport` в Angular.
- `ResizeObserver` — элемент изменил размер: адаптивные компоненты, замена ресайз-хака на window.
- `MutationObserver` — изменения DOM у элемента (добавление/удаление/атрибуты).
- Все — асинхронные и «батчевые»: не жгут главный поток в отличие от scroll/resize-обработчиков.

# AbortController: отмена запросов и подписок

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `AbortController` → `signal`; передаёшь в `fetch`, `addEventListener`, `rxjs fetch` и др.
- `controller.abort()` — все подписанные операции получают `AbortError`.
- Таймаут = `setTimeout(() => controller.abort(), ms)`.
- Кейсы: отмена при уходе с экрана, «последний запрос побеждает» в поиске (в паре с debounce), лимит времени.
- В Angular: `takeUntilDestroyed`, `switchMap` закрывают нужду руками, но AbortController — про сам HTTP.

# 08 · Событийный цикл (event loop)

## Теория (кратко)

- JS однопоточный. Устройство:
  - **стек вызовов** (call stack) — выполняется синхронный код;
  - **Web APIs** — таймеры, события, fetch живут вне потока JS;
  - **очередь макрозадач** (macrotasks): `setTimeout`/`setInterval`, события ввода, события сети;
  - **очередь микрозадач** (microtasks): колбэки промисов (`.then`/`.catch`/`.finally`),
    продолжения после `await`, `queueMicrotask`, `MutationObserver`.
- Порядок одного «такта»: **весь синхронный код → все микрозадачи до конца → одна макрозадача →
  снова все микрозадачи → …**
- Поэтому `Promise.then` всегда выполняется раньше `setTimeout(fn, 0)`: микрозадачи draining'уются
  до любой макрозадачи.
- `setTimeout(fn, 0)` — это «после текущего кода и микрозадач», а не «сейчас». Минимальная задержка
  вложенных таймеров — ~4 мс. Если основной поток занят долгими вычислениями — таймер ждёт освобождения стека.
- `await x` внутри async-функции: код после `await` продолжается как микрозадача
  (когда `x` settle).
- Бесконечная генерация микрозадач («голодание») не даёт наступить макрозадачам — страница зависает.
- `requestAnimationFrame` — отдельная очередь, выполняется перед отрисовкой кадра.
- В Node.js есть свои очереди (`process.nextTick` — раньше промисов, `setImmediate`), на фронтовом
  собеседовании про это спросят вскользь — знать на уровне «отличаются, nextTick раньше».

## Примеры

```js
console.log('1 sync');
setTimeout(() => console.log('2 macro'), 0);
Promise.resolve().then(() => console.log('3 micro'));
queueMicrotask(() => console.log('4 micro'));
console.log('5 sync');
// Порядок: 1, 5, 3, 4, 2

async function flow() {
  console.log('a');
  await null;          // продолжение — микрозадача
  console.log('b');
}
flow();
console.log('c');
// Порядок: a, c, b
```

6. Чем `await` отличается от `.then` по моменту продолжения?
7. Сколько микрозадач выполнится между двумя макрозадачами? Что такое «голодание»?
8. Перечисли микрозадачи и макрозадачи (по 3–4 примера каждой).
9. Чем `requestAnimationFrame` отличается от `setTimeout`?

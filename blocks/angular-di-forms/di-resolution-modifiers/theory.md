# Модификаторы DI: Optional, Self, SkipSelf, Host и в inject()

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `@Optional()` → inject(X, {optional: true}): нет провайдера — null вместо ошибки.
- `@Self()` → {self: true}: только собственный инжектор.
- `@SkipSelf()` → {skipSelf: true}: искать начиная с родителя (частый трюк: обёртка над родительской реализации).
- `@Host()` → {host: true}: не выше хост-компонента (граница проекции).
- `inject()` — функция нового стиля: работает в поле/конструкторе, короче, лучше типизируется; ограничение — вызывать только в injection context (при создании поля, в конструкторе или в теле factory-провайдера).

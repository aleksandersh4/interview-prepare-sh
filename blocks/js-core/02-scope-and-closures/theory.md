# 02 · Область видимости и замыкания

> Задачи — карточками на странице темы; файлы: `01-task.js`, `02-task.js`… в этой папке.

## Теория (кратко)

- **Лексическая область видимости**: функция видит переменные того места, *где она объявлена*,
  а не где вызвана. Области вложены в цепочку: внутренняя → внешняя → глобальная.
- **var** — область видимости «на функцию», объявление поднимается (hoisting) со значением `undefined`,
  повторное объявление молча разрешено.
- **let/const** — область «на блок `{}`»; до строки объявления обращение даёт `ReferenceError` —
  это **TDZ** (temporal dead zone). `const` фиксирует *привязку*, не значение: поля объекта мутировать можно.
- **Hoisting**: объявления функций поднимаются целиком (функцией можно пользоваться до строки объявления),
  `var` — только объявление (значение `undefined`).
- **Замыкание** = функция + лексическое окружение, в котором она была создана.
  Внутренняя функция сохраняет доступ к переменным внешней даже после того, как внешняя завершилась:
  сборщик мусора не удаляет окружение, пока на функцию есть ссылки.
- Где это в реальном коде: приватное состояние (фабрики), `debounce`/`throttle`, `memoize`, `once`,
  обработчики событий, каррирование, модули до эпохи ES-модулей.
- Классика собеседований: `for (var i...) setTimeout(() => log(i))` печатает последнее значение
  N раз — у всех колбэков *одна общая* переменная. `let` создаёт новую привязку на каждую итерацию.
- Минус замыканий: удержанные большие объекты не собираются сборщиком — утечка памяти.

## Примеры

```js
function makeCounter() {
  let count = 0;            // живёт в замыкании
  return () => ++count;
}
const a = makeCounter();
a(); a();                   // 2
const b = makeCounter();    // независимый счётчик: у каждого вызова своё окружение

// Классика:
for (var i = 1; i <= 3; i++) setTimeout(() => console.log('var:', i)); // 4, 4, 4
for (let j = 1; j <= 3; j++) setTimeout(() => console.log('let:', j)); // 1, 2, 3

// TDZ:
console.log(x);             // ReferenceError (let ниже)
let x = 1;
```

## Задачи (карточки на странице)

1. **`makeCounter()`** — счётчик с приватным состоянием, независимые экземпляры.
2. **`createStack()`** — стек, у которого массив `items` недоступен снаружи.
3. **`once(fn)`** — функция, вызывающая `fn` только первый раз и кэширующая результат.
4. **`memoize(fn)`** — кэш результатов по аргументам.
5. **`debounce(fn, ms)`** — вызов не раньше, чем через `ms` после последнего вызова.
6. **`throttle(fn, ms)`** — не чаще одного раза в `ms` (первый вызов — сразу).
7. Демо `var` vs `let` в цикле — объясни вывод.

_Тесты к 5–6 с таймерами: их результаты допишутся в вывод чуть позже — это нормально._

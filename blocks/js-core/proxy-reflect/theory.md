# Proxy и Reflect: как устроена реактивность

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `Proxy(target, handlers)` — обёртка над объектом: перехват `get/set/deleteProperty/has/apply` и др.
- `Reflect` — «зеркальный» API тех же операций (для корректного форварда дефолтного поведения внутри ловушек: `Reflect.get(target, key, receiver)`).
- На этом строятся: Vue 3 reactivity, MobX; в Angular — signals работают иначе (явные зависимости), но RxJS/байндинги — смежная идея «перехватил чтение/запись → уведомил».
- Отменяемость: `revoke()` у `Proxy.revocable`.

# 01 · Типы данных и приведение типов

> Задачи — карточками на странице темы; файлы: `01-task.js`, `02-task.js`… в этой папке.

## Теория (кратко)

- В JS **8 типов**: 7 примитивов (`number`, `string`, `boolean`, `undefined`, `null`, `symbol`, `bigint`)
  и `object` (включая массивы, функции, даты).
- Примитив хранится **по значению**, объект — **по ссылке** (подробно — тема 06).
- `typeof`:
  - `typeof null === 'object'` — исторический баг языка, null не объект;
  - `typeof function(){} === 'function'` — единственное «исключение» среди объектов;
  - для остальных — имя типа (`'number'`, `'string'`, `'boolean'`, `'undefined'`, `'symbol'`, `'bigint'`, `'object'`).
- **Приведение (coercion)**:
  - явное — ты вызываешь `Number('5')`, `String(5)`, `Boolean(x)`;
  - неявное — делает движок: операторы `+ - == < !` и др.
- Правило «плюса»: если один операнд строка — второй приводится к строке (конкатенация).
  Все остальные арифметические операторы ведут к числу: `'5' - 2 === 3`, но `'5' + 2 === '52'`.
- `==` перед сравнением приводит типы: `null == undefined` (и только они друг к другу),
  строки/булевы → числа, объект → примитив. `===` не приводит ничего.
- `NaN` не равен ничему, **включая себя**: `NaN === NaN → false`. Проверка — `Number.isNaN(v)`
  (а не глобальный `isNaN`, который приводит аргумент к числу).
- **Falsy** ровно 7: `false, 0, -0, 0n, '', null, undefined, NaN`. Всё остальное truthy —
  включая `'0'`, `'false'`, `[]`, `{}`.
- `null` — «намеренно пусто» (присваивает программист), `undefined` — «значение не задано»
  (переменная объявлена, но не инициализирована; нет свойства; нет результата функции).
- `Object.is(a, b)` — как `===`, но `Object.is(NaN, NaN) === true` и `Object.is(0, -0) === false`.

## Примеры

```js
typeof null;            // 'object' — баг, но так живут
typeof [];              // 'object' — массив проверяют через Array.isArray
'5' + 3;                // '53'   — строка «победила»
'5' - 3;                // 2      — минус приводит к числам
[] + [];                // ''     — оба к строкам: '' + ''
null == undefined;      // true — единственная «пара» для ==
null >= 0;              // true — сравнение приводит null к 0 (!)
Boolean([]);            // true — пустой массив truthy
Number.isNaN(NaN);      // true
Object.is(0, -0);       // false
```

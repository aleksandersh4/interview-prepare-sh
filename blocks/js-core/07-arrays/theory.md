## Теория (кратко)

- **Не мутирующие** (возвращают новое): `map`, `filter`, `slice`, `concat`, `flat/flatMap`,
  `find/findIndex/findLast`, `some/every`, `reduce/reduceRight`, `join`, `at`,
  `toSorted/toReversed/toSpliced/with` (ES2023).
- **Мутирующие** (меняют исходник): `push/pop/shift/unshift`, `splice`, `sort`, `reverse`,
  `fill`, `copyWithin`. Сортированная копия: `[...arr].sort()` или `arr.toSorted()`.
- `reduce((acc, item, index, arr) => newAcc, initialValue)`:
  - без `initialValue` первым аккумулятором становится **первый элемент**;
  - пустой массив без `initialValue` → `TypeError`;
  - `reduce` умеет всё: сумму, группировку, подсчёт, разворот, даже map/filter на его основе.
- Поиск: `indexOf/lastIndexOf/includes` (по `===`; `includes`, в отличие от `indexOf`, находит `NaN`).
- `forEach` нельзя прервать (`break` не работает) — для досрочного выхода `some`/`every`
  или `for...of` + `break`.
- `map` vs `forEach`: `map` строит и возвращает новый массив, `forEach` возвращает `undefined` —
  использовать `map` «просто для перебора» считается ошибкой.
- Создание/преобразование: `Array.from(iterable | "abc", mapFn)`, `Array.of(...)`, `[...iterable]`.
- Массив — тоже объект: у него `length`, могут быть «дыры» (sparse arrays); проверка — `Array.isArray`
  (`typeof [] === 'object'`, `instanceof` может врать между окнами/реймами).
- `sort` по умолчанию сравнивает **строки**: `[10, 9, 1].sort()` → `[1, 10, 9]`.
  Для чисел — компаратор `(a, b) => a - b`.

## Примеры

```js
[1, 2, 3, 4].reduce((acc, n) => acc + n, 0);      // 10
[10, 9, 1].sort();                                // [1, 10, 9] — строки!
[10, 9, 1].sort((a, b) => a - b);                 // [1, 9, 10]

[1, 2, 3].filter((n) => n > 1).map((n) => n * 2); // [4, 6]

Array.from('абв');                                 // ['а','б','в']
Array.from({ length: 3 }, (_, i) => i * 2);       // [0, 2, 4]

[1, [2, [3, [4]]]].flat(Infinity);                // [1, 2, 3, 4]

const byDept = users.reduce((acc, u) => {
  (acc[u.dept] ||= []).push(u);                    // группировка — классика собесов
  return acc;
}, {});
```

## Задачи (карточки на странице)

1. **`myMap(arr, fn)`** — полифилл map: новый массив, индекс доступен, вход не мутируется.
2. **`myReduce(arr, fn, initial)`** — полифилл reduce, включая вариант без `initial`.
3. **`unique(arr)`** — дедупликация с сохранением порядка первых вхождений.
4. **`flatten(arr)` / `flattenDeep(arr)`** — развернуть вложенность на один уровень / полностью.
5. **`groupBy(arr, fn)`** — группировка объектов по ключу из `fn(item)`.
6. **`chunk(arr, size)`** — нарезать массив кусками, последний может быть короче.
7. Демо мутации `sort` — объясни.

# Symbol, итераторы и генераторы

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `Symbol` — уникальный примитив: `Symbol("a") !== Symbol("a")`; «скрытые» свойства объекта (не видны в `for…in`, `Object.keys`).
- Известные символы: `Symbol.iterator`, `Symbol.asyncIterator`, `Symbol.hasInstance`.
- Итерируемое = объект с `Symbol.iterator` → возвращает итератор `{ next(): {value, done} }`. Так работают `for…of`, spread, деструктуризация.
- Генератор `function*` + `yield` — удобный способ сделать итератор с сохранением контекста между `next()`; `yield*` — делегирование.
- Асинхронные итераторы: `for await…of`, генераторы `async function*`.

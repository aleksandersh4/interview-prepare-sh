# Сборка мусора V8 и утечки в SPA

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- GC корни: глобальные объекты, текущий стек; недостижимое — собирается.
- V8: поколения Young (частый быстрый Scavenge) / Old (Mark-and-Sweep/Compact); объекты, пережившие сборки, переезжают.
- Типичные утечки SPA: забытые `setInterval`, слушатели событий без `removeEventListener`, замыкания, держащие большие объекты, глобальные кеши без лимита, «отвалившиеся» DOM-ссылки в переменных.
- Диагностика: DevTools Memory — Heap Snapshot (сравнение до/после), Allocation Timeline; Performance для GC-пауз.

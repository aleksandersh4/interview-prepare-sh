## Теория (кратко)

- У каждого объекта есть скрытое свойство `[[Prototype]]` (доступ — `__proto__` или
  `Object.getPrototypeOf(obj)`). У функций есть своё свойство `prototype` — оно становится
  `[[Prototype]]` объектов, созданных через `new`.
- Чтение свойства идёт **по цепочке прототипов**: свойство нет на объекте → смотрим в прототип →
  в прототип прототипа → … → `null`. Запись же почти всегда создаёт свойство на самом объекте.
- `new Ctor(...)` делает по шагам:
  1. создаёт пустой объект;
  2. ставит ему `[[Prototype]] = Ctor.prototype`;
  3. вызывает `Ctor` с `this` = новый объект;
  4. возвращает объект (если конструктор не вернул свой объект — тогда его).
- `Object.create(proto)` — объект с заданным прототипом, без конструктора.
  `Object.create(null)` — объект вообще без прототипа (нет даже `toString`).
- `instanceof` идёт по цепочке прототипов объекта и сравнивает с `Ctor.prototype`.
- **Классы** — надстройка над прототипами, но не «просто сахар»:
  - методы попадают на `Ctor.prototype`, `static` — на сам класс;
  - обязателен `new` (без него — ошибка), класс нельзя «поднять» до объявления (TDZ);
  - `extends` + `super(...)` в конструкторе, `super.method()` в методах;
  - приватные поля `#count` — реально приватные (снаружи ошибка), поля-стрелки фиксируют `this`;
  - геттеры/сеттеры: `get name() {...}`.
- Наследование в ES5-стиле: `Child.prototype = Object.create(Parent.prototype)` +
  вызов `Parent.call(this, ...)` в конструкторе. `Object.create`, а не присваивание
  `Child.prototype = Parent.prototype` (тогда общие методы) и не `new Parent()` (лишний вызов конструктора).

## Примеры

```js
function Person(name) { this.name = name; }
Person.prototype.greet = function () { return 'Я ' + this.name; };

class Animal {
  #secret = 'ы';                 // приватное поле
  constructor(name) { this.name = name; }
  introduce() { return 'Я ' + this.name; }
  static kind(o) { return o instanceof Animal; }
}
class Dog extends Animal {
  constructor(name, breed) { super(name); this.breed = breed; }
  bark() { return 'Гав!'; }
}

Object.getPrototypeOf({}) === Object.prototype;   // true
Object.create(null);                              // «пустый» объект без цепочки
```

# Кастомные операторы и планировщики

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Оператор — функция `(source: Observable) => Observable`: `pipe(source => …)`; чистые операторы через `pipe()` без new.
- `defer` — ленивое создание; `tap/do` — сайд-эффекты (лог, лоадер); `observeOn/subscribeOn` — планировщики.
- Schedulers: какая «единица времени» и где выполняется колбек (queue/async/animationFrame); в браузерном коде почти не нужны, знать концепцию.

## Что могут спросить дополнительно
- Напиши логирующий оператор: `source => source.pipe(tap(console.log))`.

## Красные флажки
- Кастомный оператор с состоянием без создания нового Observable на подписку.

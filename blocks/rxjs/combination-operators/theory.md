# combineLatest, forkJoin, zip, withLatestFrom, merge, concat

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `combineLatest` — последние значения каждого источника, эмитит когда ВСЕ хоть раз эмитнули, дальше на каждое изменение (карточка из нескольких источников).
- `forkJoin` — последние значения, эмитит ОДИН раз когда все ЗАВЕРШИЛИся (Promise.all; параллельные запросы). Пустой/ошибка — нюансы.
- `zip` — по индексу: n-е с n-м, ждёт пару (редко, но любят спрашивать).
- `withLatestFrom` — главный поток + снапшот второго (клик + текущий фильтр), второй не триггерит.
- `merge` — всё в один поток (события разных кнопок); `concat` — сначала первый до конца, потом второй.

## Что могут спросить дополнительно
- combineLatest почему «дёргается» на каждый чих и как фильтровать (distinctUntilChanged, правильные источники).
- forkJoin с пустым массивом — завершится без эмита!

## Красные флажки
- combineLatest для «одноразовых запросов» (нужен forkJoin).

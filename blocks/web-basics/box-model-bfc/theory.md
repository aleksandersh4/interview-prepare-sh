# Box Model, схлопывание отступов и BFC

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Box model: content + padding + border + margin. `box-sizing: border-box` — width включает padding и border.
- В проектах ставят `* { box-sizing: border-box }` — предсказуемая математика.
- Margin collapsing: вертикальные margin соседей/родителя и ребёнка схлопываются в больший — только в блочном контексте.
- Не схлопываются: flex/grid-дети, absolute, у которых задан `overflow` не `visible`…
- BFC (Block Formatting Context) — изолированная область раскладки: не схлопывается с внешними margin, не обтекается флоатами, содержит флоаты.
- Триггеры BFC: `overflow: hidden/auto`, `display: flow-root` (чистый способ), flex/grid контейнеры.

## Что могут спросить дополнительно
- Как убрать схлопывание? (`display: flow-root` родителю, padding/border между)
- Практический кейс: флоат-обёртка/схлопнувшийся родитель.

## Красные флажки
- «Схлопываются и горизонтальные» — нет, только вертикальные.

# Специфичность CSS, каскад и !important

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Специфичность: инлайн (1,0,0,0) > id (0,1,0,0) > класс/атрибут/псевдокласс (0,0,1,0) > элемент (0,0,0,1).
- Считается по « столбцам » независимо: 1 id перебьёт сколько угодно классов.
- Каскад: при равной специфичности побеждает последний; источники — user agent < user < author.
- Наследование: цвет/шрифт наследуются, box-свойства — нет.
- `!important` ломает каскад — допустим только как временный костыль или в утилитах; в проекте его минимизируют.

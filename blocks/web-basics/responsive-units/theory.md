# Адаптивность: медиа-запросы, единицы, clamp()

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Mobile-first: базовые стили под узкий экран, `@media (min-width: …)` наращивает.
- Единицы: `rem` (корневой, масштабируется с настройками шрифта — доступность), `em` (от родителя), `vw/vh` (вьюпорт; `dvh` корректен на мобильных с адресной строкой), `%`.
- Функции: `clamp(min, ideal, max)` — типографика/отступы без медиа-запросов; `min()/max()`.
- `container queries` (`@container`) — компонент реагирует на свой контейнер, а не вьюпорт — следующий шаг после БЭМ-компонентности.

## Что могут спросить дополнительно
- Почему `rem`, а не `px` для шрифтов? (пользовательские настройки размера шрифта)
- Разница `vh` и `dvh` на мобильных.
- Как бы сделал резиновый флюид-заголовок? (`clamp(1.5rem, 4vw, 3rem)}`)

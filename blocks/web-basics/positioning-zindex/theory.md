# Позиционирование и stacking context

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- `static` (нормальный поток) / `relative` (сдвиг от себя, место сохраняется) / `absolute` (от ближайшего positioned-родителя) / `fixed` (от вьюпорта; `transform` у предка делает его «вьюпортом»!) / `sticky` (липнет в пределах родителя).
- `absolute/fixed` вынимают из потока — родитель схлопывается.
- z-index работает только на positioned-элементах (или flex/grid-детях).
- Stacking context создаётся: z-index на positioned, `opacity < 1`, `transform`, `filter`, `isolation: isolate`…
- z-index сравнивается ВНУТРИ одного контекста: у ребёнка z-index: 999999 не выпрыгнет из контекста родителя с z-index: 1.

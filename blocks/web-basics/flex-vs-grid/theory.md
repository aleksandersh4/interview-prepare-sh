# Flexbox против CSS Grid

> Теоретическая тема. Попроси ассистента: «проверь меня: <тема>» — он устроит устный опрос по вопросам ниже.

## Как отвечать (скелет)
- Flexbox — одномерный (ось + перенос), контент-driven: размеры от содержимого.
- Grid — двумерный, layout-driven: сетка задаётся контейнером (`grid-template-columns/areas`).
- Правило: раскладка страницы/дашборда — Grid; ряд кнопок/меню/строка формы — Flex.
- Отлично сочетаются: Grid для каркаса, Flex внутри ячеек.
- Упомянуть `gap`, `auto-fit/minmax()` для адаптива без медиа-запросов.

## Что могут спросить дополнительно
- `fr` — что это? (доля свободного пространства)
- `auto-fill` vs `auto-fit` (схлопывание пустых треков у auto-fit)
- Когда Flex не справляется, а Grid тривиально решает (шапка-сайдбар-контент-футер).

## Красные флажки
- «Grid просто новее, всегда бери его» — вопрос о критерии выбора осей.
